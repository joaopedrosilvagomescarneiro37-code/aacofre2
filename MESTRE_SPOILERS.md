# SOMENTE PARA O MESTRE — GABARITO

Não compartilhe este documento com os jogadores. Ele não integra a interface nem os arquivos do build `dist/`.

Todos os símbolos abaixo são aberturas físicas: N = cima, S = baixo, L = direita e O = esquerda.

| | Coluna 1 | Coluna 2 | Coluna 3 | Coluna 4 |
|---|---|---|---|---|
| Linha 1 | SO | SL | LO | SO |
| Linha 2 | NS | NS | SL | NO |
| Linha 3 | NL | NO | NL | SO |
| Linha 4 | LO | LO | LO | NO |

A entrada fica à esquerda de (1,1); o retorno à esquerda de (4,1).

Percurso: (1,1), (2,1), (3,1), (3,2), (2,2), (1,2), (1,3), (1,4), (2,4), (2,3), (3,3), (3,4), (4,4), (4,3), (4,2), (4,1).

Para testar rapidamente a partir do estado inicial, selecione a primeira peça e pressione R a quantidade indicada em cada célula. Use as setas para passar à próxima. Cada número é uma quantidade de giros horários, não uma senha.

| | C1 | C2 | C3 | C4 |
|---|---|---|---|---|
| L1 | 2 | 3 | 1 | 2 |
| L2 | 1 | 1 | 3 | 2 |
| L3 | 3 | 3 | 2 | 2 |
| L4 | 1 | 1 | 1 | 2 |

Acione a bomba. O preenchimento leva aproximadamente sete segundos; a pressão e o mecanismo levam cerca de mais cinco segundos. A porta só fica disponível após a batida. Arraste o puxador para a esquerda ou use o botão inferior para puxá-la gradualmente.

A sirene permite apenas uma utilização relevante na ficção. O site registra a descoberta, sem controlar a duração ou consumir o uso: isso fica com o mestre. O croqui é esquemático e adaptável ao balneário da campanha. O relatório não contém uma segunda senha.
